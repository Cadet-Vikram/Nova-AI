# NOVA Website

## Deploy to GitHub Pages

1. Upload all files in this folder to your `Cadet-Vikram/Nova-AI` repo
2. Go to repo **Settings → Pages → Source → Deploy from branch → main → / (root) → Save**
3. Site goes live at: `https://cadet-vikram.github.io/Nova-AI`

## Host the installer

1. Go to repo → **Releases → Draft a new release**
2. Tag: `v1.0.0` · Title: `NOVA v1.0.0 — Offline AI Assistant`
3. Upload `AI Assistant Setup.exe` as release asset
4. Publish release → download link works automatically
