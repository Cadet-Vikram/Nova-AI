Features

Everything you need, nothing you don't

NOVA is built around one principle — your AI assistant should work for you, not report back to a server.

Core

Streaming chat

Responses stream token-by-token as the model generates them — exactly like ChatGPT, but entirely on your machine. No waiting for a full response to arrive.

Conversations are saved locally and organized in a sidebar so you can pick up where you left off.

  • Full conversation history
  • Markdown and code block rendering
  • System prompt customization per session

Voice

Offline voice input

Speak naturally and NOVA transcribes your words using faster-whisper running locally on your CPU. No microphone data is ever sent to any server.

Click the mic — speak as long as you need — click again to stop and send. Words appear in the input box in real time.

  • Powered by OpenAI Whisper (local)
  • Works with any Windows microphone
  • Transcribes in rolling 4-second chunks
  • Auto-sends when you stop recording

Documents

Ask questions about your files

Attach a document to your conversation and ask anything about it. NOVA reads the content and answers based on what's in the file.

  • PDF files
  • Word documents (.docx)
  • Plain text and Markdown

Great for summarizing reports, extracting key points from contracts, or understanding long documents quickly.

📄 Q3_Report.pdf ✕
What were the top 3 risks mentioned?
⬡ Based on the document, the top risks are: supply chain delays, rising material costs, and regulatory changes in Q4.
Customization

Settings built for power users

Every aspect of the assistant's behavior is configurable through the settings panel.

  • Model selector — switch between installed Ollama models
  • Temperature — control creativity vs. precision
  • Context window — tune speed vs. memory
  • System prompt — define the AI's persona
  • Theme — Dark, Dim, or Light
  • Accent color — 6 presets + custom picker
  • Keyboard shortcuts — rebind anything
