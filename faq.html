Installation

This is a Windows SmartScreen warning that appears for apps that aren't code-signed. NOVA is open source and safe — you can inspect the full source code on GitHub. Click "More info" then "Run anyway" to proceed.

The installer bundles everything needed to run offline: the Electron app (~150 MB), Ollama runtime (~90 MB), and the Phi-3 AI model (~2.3 GB). This is intentional — after installation, no internet is needed at all.

The installer asks for admin rights to install to Program Files. If you don't have admin rights, choose a different installation directory (like your Documents folder) during setup.

Performance

This usually means Ollama didn't start correctly. Try:

  1. Close and reopen NOVA
  2. Check Task Manager for ollama.exe — if it's there, wait 10 seconds and try again
  3. If it's not there, NOVA may have had trouble starting it. Open a terminal and run ollama serve manually, then reopen NOVA

NOVA runs on CPU by default, which is slower than cloud AI. To improve speed:

  • Switch to Phi-3 in the model dropdown (faster than Llama 3)
  • Lower the context window to 1024 in settings
  • Lower max tokens to 512
  • Close other memory-heavy applications
  • If you have an NVIDIA GPU, set GPU layers to 20–35 in settings

It depends on the model. Phi-3 Mini needs about 3–4 GB of RAM for the model itself. We recommend 8 GB total system RAM as a minimum, with 16 GB for a comfortable experience. Llama 3 (8B) requires about 6–8 GB for the model.

This usually means NOVA can't find your Python installation. Try:

  1. Open a terminal and run: python -c "import faster_whisper; import sounddevice; print('OK')"
  2. If that prints OK but the app still shows the error, restart NOVA after installing
  3. Make sure Python is added to your system PATH during installation

This is a Windows microphone privacy issue. Go to Win + I → Privacy & Security → Microphone and make sure "Let desktop apps access your microphone" is turned ON. Also check that your microphone volume isn't set to 0 in Sound Settings.

Whisper transcription runs on CPU and takes 1–5 seconds per 4-second audio chunk depending on your hardware. This is normal. The transcription happens in the background — you'll see words appear in the input box as each chunk completes.
