Quick start

Get NOVA running in under 5 minutes.

1

Download the installer

Go to the download page and click Download NOVA. The installer is about 5 GB and includes everything you need.

2

Run the installer

Double-click AI Assistant Setup.exe. Click Next → Install → Finish. Windows may show a SmartScreen warning — click "More info" then "Run anyway" since NOVA is not yet code-signed.

3

Launch NOVA

Open NOVA from your desktop shortcut or Start menu. The first launch takes 15–30 seconds as the AI model loads. After that, it's instant.

4

Start chatting

Type your message and press Enter. You should see the AI response streaming in within a few seconds. You're all set!

Installation details

NOVA installs to C:\Program Files\AI Assistant\ by default. You can change this during setup.

The installer creates:

  • A desktop shortcut
  • A Start menu entry under AI Assistant
  • An uninstaller accessible from Windows Settings → Apps
Note: The installer bundles Ollama and the Phi-3 model. If you already have Ollama installed on your system, NOVA will use its own bundled version to avoid conflicts.

First launch

On first launch, NOVA automatically starts Ollama in the background. You'll see the status indicator in the bottom-left sidebar turn green when Ollama is connected and ready.

If it stays red, see the FAQ: Ollama shows offline.

Chatting

Type your message in the input box at the bottom and press Enter to send. Use Shift+Enter to add a new line without sending.

Responses stream in as they're generated. You can start reading the answer before it's finished.

Past conversations appear in the left sidebar. Click any to continue from where you left off.

Voice input

Click the microphone button (🎤) in the input area to start recording. Speak naturally — NOVA transcribes your words in real time using Whisper running locally.

Click the mic again (or press Enter) to stop recording and send the message automatically.

First time only: Voice input requires Python with faster-whisper installed. If prompted, run: pip install faster-whisper sounddevice in a terminal.

Make sure Windows mic privacy is enabled: Win + I → Privacy & Security → Microphone → Let desktop apps access your microphone → ON

Document reading

Click the 📎 button in the top bar to attach a file. Supported formats:

  • PDF (.pdf)
  • Word documents (.docx)
  • Plain text (.txt)
  • Markdown (.md)

After attaching, type your question as normal. The first 5,000 characters of the file will be included as context for the AI.

Switching models

Use the model dropdown in the sidebar to switch between installed models. To add a new model, open a terminal and run:

ollama pull mistral

The new model will appear automatically in the dropdown after restarting NOVA.

Performance tips

NOVA runs on CPU by default. For faster responses:

  • Use Phi-3 — it's 2–3× faster than Llama 3 on CPU
  • Lower the context window — set it to 1024 or even 512 in settings for much faster responses
  • Lower max tokens — set to 512 for quick answers
  • Close other apps — LLMs are memory-intensive

GPU acceleration

If you have an NVIDIA GPU, you can speed up NOVA significantly:

  1. Open Settings → Model & Performance
  2. Set GPU Layers to 20–35
  3. Start a new chat — responses should be noticeably faster

To find your GPU: press Win+R, type dxdiag, go to the Display tab.

Intel integrated graphics (UHD, Iris) are not supported for GPU acceleration. AMD GPU support depends on your Ollama version.
